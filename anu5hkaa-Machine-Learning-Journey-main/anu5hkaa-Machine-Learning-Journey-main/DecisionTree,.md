# Machine Learning Notes – My Understanding 

# Decision Tree

A Decision Tree is a supervised learning algorithm used for both:

* Classification
* Regression

It keeps splitting the data based on different conditions.

Its objective is to reduce impurity after every split.

Two common impurity measures are:

* Gini Index
* Entropy (Information Gain)

Information Gain is basically the reduction in uncertainty after making a split.

The biggest limitation of Decision Trees is overfitting.

Deep trees memorize the training data.

Pruning helps,

but sometimes useful information is also lost.

This is why Ensemble Learning is often preferred.
