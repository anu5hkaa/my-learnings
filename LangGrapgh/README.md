# LangGraph Practice

This repository is my personal practice space for learning and improving my knowledge of **LangGraph**.

I am practicing LangGraph every day to sharpen my understanding of:
- State and StateGraph
- Nodes and Edges
- Conditional Routing
- Loops
- Memory
- Tool Calling
- ReAct Agents
- RAG
- Hybrid Retrieval
- Query Transformation
- Reranking
- Multimodal RAG
- and other LLM application concepts

The goal of this repository is to practice consistently, experiment with different ideas, and gradually build a stronger understanding of LangGraph and LLM-based applications.

## Why This Repository?

I believe consistent hands-on practice is one of the best ways to improve technical skills.

I am using this repository to:
- Practice LangGraph every day
- Build small projects and workflows
- Experiment with different techniques
- Learn from errors and debugging
- Track my progress over time
- Sharpen my understanding of LLM applications
